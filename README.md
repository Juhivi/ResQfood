# ResQFood — Hackathon Website Demo

This is a self-contained front-end MVP created from the ResQFood pitch deck and the supplied prototype screens.

## Run
1. Extract the folder.
2. Double-click `index.html` to open it in a browser.
3. For the best local demo, run a simple local server (for example VS Code Live Server).

## Demo flow
Dashboard → New Donation → Submit → AI NGO Matching → Select NGO → Volunteer Tasks → Mark Pickup Completed → Confirm Delivery → Impact Analytics.

## Important
This is a **hackathon demo/MVP**. Data is stored in browser `localStorage`; AI matching and QR verification are simulated for the demo. It does not yet include a production backend, real authentication, live maps, real QR scanning, or a real AI API.

The UI and workflow are based on the ResQFood pitch deck: four roles, list → match → pickup → verify, explainable matching, QR/status handoff, alerts, audit-oriented records, and impact analytics.
